Galaxy Data → Google Sheets Export

Step 1 — Download the 5 CSV files

Step 2 — Import into Google Sheets

  1. Open your blank Google Sheet.
  2. For each CSV: click the sheet tab at the bottom → rename it to match the filename (e.g. nodes, progressions, etc.).
  3. With that tab selected, go to File → Import → Upload and choose the CSV. Select "Replace current sheet" and "No" for converting numbers.
  4. Repeat for all 5 files.

Step 3 — Publish as CSV

  1. Go to File → Share → Publish to web.
  2. For each tab, choose the tab name in the first dropdown and Comma-separated values (.csv) in the second.
  3. Click Publish and copy the URL — you need one URL per tab (5 total).
  4. Paste the 5 URLs into js/sheets-config.js in the project.

Tip: enable "Automatically republish when changes are made" so edits in Sheets go live immediately.
